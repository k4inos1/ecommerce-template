# GitHub Copilot Automation Configuration

## 🤖 Copilot Automation Rules for ecommerce-delivery-app

### PR Review Automation

**Triggers:**
- `review: auto` → Genera automáticamente sugerencias de review
- `security: scan` → Ejecuta security scan con Trivy
- `test: run` → Ejecuta test suite
- `deploy: check` → Verifica readiness para deploy

### Auto-Merge Rules

```yaml
Conditions para auto-merge:
  - All checks passing (ESLint, Tests, Security) ✅
  - Approved by security team (si hay cambios de seguridad)
  - No conflicts ✅
  - Coverage no baja ✅

Exclusiones (Manual review requerido):
  - Cambios en payment processing
  - Cambios en auth/JWT
  - Cambios en database models
  - Cambios en delivery tracking
  - Cambios en Stripe/Transbank integration
```

### Copilot Commands

```
# PR Analysis
@copilot review: auto              # Auto-review PR
@copilot check: security           # Verificar seguridad
@copilot check: performance        # Verificar performance
@copilot test: run                 # Ejecutar tests

# Deployment
@copilot deploy: staging           # Deploy a staging
@copilot deploy: production        # Deploy a producción
@copilot verify: deployment        # Verificar deployment

# Documentation
@copilot docs: update              # Actualizar docs
@copilot changelog: generate       # Generar changelog
```

### Auto-Labels

```yaml
Backend changes → 'backend'
Frontend changes → 'frontend'
Database changes → 'database' + 'needs-review'
API changes → 'api'
Security changes → 'security' + 'needs-review'
Bug fix → 'bug'
Feature → 'feature'

```
